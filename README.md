# CRM พงษ์สกุล — เวอร์ชันออนไลน์

เว็บ CRM ที่เปิดใช้ผ่านลิงก์ (https) จากคอมพิวเตอร์หรือมือถือเครื่องไหนก็ได้ **โดยไม่ต้องเปิดคอมที่ออฟฟิศทิ้งไว้**
เหมาะกับทีมเล็ก (เซลล์ / หัวหน้า / ผู้พัฒนา-ผู้ดูแล) ใช้ Flask + SQLite เก็บข้อมูลบนเซิร์ฟเวอร์ที่เช่า

## สิ่งที่ได้ในเวอร์ชันนี้

| ฟีเจอร์ | รายละเอียด |
|---|---|
| ล็อกอินแยกคน | ชื่อผู้ใช้ + รหัสผ่าน (เก็บแบบเข้ารหัส) ชื่อเซลล์ในบันทึกการติดต่อถูกล็อกตามบัญชี แก้เป็นชื่อคนอื่นไม่ได้ |
| 3 บทบาท | **เซลล์** บันทึก/แก้ข้อมูลได้ · **หัวหน้า** เพิ่ม: ลบข้อมูล, จัดการรายการสินค้า, ส่งออก Excel · **ผู้ดูแล** เพิ่ม: จัดการผู้ใช้, ดาวน์โหลดไฟล์สำรอง |
| บันทึกทีละรายการ | แก้คนละรายการพร้อมกันได้โดยไม่ทับกัน ถ้าแก้ **รายการเดียวกัน** พร้อมกัน ระบบจะไม่เขียนทับเงียบ ๆ แต่แจ้งคนที่บันทึกทีหลังให้ตรวจและกรอกซ้ำ |
| เห็นข้อมูลของกันและกัน | หน้าเว็บตรวจข้อมูลใหม่ทุก 8 วินาที (ไม่ต้องกดรีเฟรช) |
| สำรองข้อมูล | สำรองอัตโนมัติทุกวัน (เก็บ 14 วัน) บนเซิร์ฟเวอร์ + ผู้ดูแลกดดาวน์โหลดไฟล์สำรองเก็บไว้เองได้ |
| หน้าจอเดิมครบ | ภาพรวม / สรุปรายงาน (วัน-เดือน-ปี) / บันทึกการติดต่อ / ออเดอร์ & ขนส่ง / ติดตามลูกค้า / ส่งออก |

## ขั้นที่ 0 (แนะนำ): ลองบนคอมพิวเตอร์ก่อน

ดับเบิลคลิก **`try_local.bat`** (ต้องมี Python — ที่คุณติดตั้งไว้แล้ว) เบราว์เซอร์จะเปิด `http://localhost:5055`
ล็อกอินด้วยผู้ใช้ `admin` รหัสผ่าน `Test12345678` ลองเพิ่มผู้ใช้เซลล์ แล้วเปิดอีกหน้าต่าง (หรือโหมดไม่ระบุตัวตน) ล็อกอินเป็นอีกคนเพื่อดูการทำงานร่วมกัน
ข้อมูลทดลองอยู่ในโฟลเดอร์ `data_test` ลบทิ้งได้เมื่อเลิกทดลอง · **อย่าใช้รหัสนี้บนเซิร์ฟเวอร์จริง**

## ขั้นตอนนำขึ้นออนไลน์ (Render)

> Render เป็นผู้ให้เช่าเซิร์ฟเวอร์ ให้ลิงก์ฟรีรูปแบบ `https://ชื่อ.onrender.com` จึง **ไม่ต้องซื้อโดเมนก่อน**
> ต้องใช้แผนเสียเงิน (Starter) เพราะต้องมี "ดิสก์ถาวร" เก็บฐานข้อมูล แผนฟรีเก็บข้อมูลไม่อยู่ — ราคาโดยประมาณ **$7/เดือน + ดิสก์ $0.25/GB/เดือน** (ราว ๆ $7–8 ต่อเดือนสำหรับ 1 GB) ตรวจราคาล่าสุดที่ <https://render.com/pricing> ก่อนกดยืนยัน

### 1) เอาไฟล์ขึ้น GitHub (ที่เก็บโค้ด)
1. สมัคร <https://github.com> (ฟรี) → กด **New repository** → ตั้งชื่อ เช่น `pongsakul-crm` → เลือก **Private** → Create
2. ในหน้า repository กด **uploading an existing file** แล้วลากไฟล์/โฟลเดอร์ทั้งหมดในแพ็กเกจนี้เข้าไป (ต้องให้ `render.yaml` และ `app.py` อยู่ชั้นนอกสุด และมีโฟลเดอร์ `static` ด้วย) → กด **Commit changes**
3. ห้ามอัปโหลดโฟลเดอร์ `data`, `data_test`, `venv` (ถ้ามี) เพราะอาจมีข้อมูลลูกค้า

### 2) สร้างบริการบน Render
1. สมัคร <https://render.com> → เข้า Dashboard → **New +** → **Blueprint**
2. เชื่อมบัญชี GitHub แล้วเลือก repository `pongsakul-crm`
3. Render อ่าน `render.yaml` แล้วจะถามค่า **`CRM_ADMIN_PASSWORD`** → ตั้งรหัสผ่านผู้ดูแลคนแรก (อย่างน้อย 8 ตัวอักษร ควรยาวและเดายาก) → กด **Apply**
4. รอสักครู่จนสถานะเป็น **Live** (ครั้งแรกใช้เวลาหลายนาที) แล้วกดลิงก์ `https://….onrender.com` ที่ด้านบนของหน้าบริการ

> ถ้าไม่ใช้ Blueprint: **New + → Web Service** เลือก repo → Language `Python 3` → Build Command `pip install -r requirements.txt` → Start Command `python app.py` → Instance Type **Starter** → เพิ่ม **Disk** (Mount Path `/var/data`, ขนาด 1 GB) → ใส่ Environment Variables ตาม `render.yaml` (`CRM_DATA_DIR=/var/data`, `CRM_BEHIND_PROXY=1`, `CRM_ADMIN_USER=admin`, `CRM_ADMIN_PASSWORD=...`) และตั้ง Health Check Path เป็น `/healthz` ชื่อเมนูใน Render อาจต่างจากนี้เล็กน้อย

### 3) เข้าใช้งานครั้งแรก
1. เปิดลิงก์ → ล็อกอินด้วย `admin` และรหัสที่ตั้งไว้
2. กด **เปลี่ยนรหัสผ่าน** (แถบด้านบน) ถ้าต้องการรหัสที่เฉพาะตัว
3. เมนู **ผู้ใช้** → **+ เพิ่มผู้ใช้** สร้างบัญชีเซลล์ / หัวหน้า / ผู้พัฒนา ให้แต่ละคน แล้วส่งชื่อผู้ใช้กับรหัสเริ่มต้นให้เจ้าตัว (ให้เปลี่ยนรหัสเองหลังเข้าใช้)
4. ให้ทุกคนเปิดลิงก์เดียวกัน บนมือถือกด "เพิ่มไปที่หน้าจอโฮม" เพื่อใช้เหมือนแอปได้

หลังสร้างผู้ดูแลแล้ว ตัวแปร `CRM_ADMIN_PASSWORD` ไม่ถูกใช้อีก (จะลบออกจาก Environment ก็ได้)

## การดูแลระบบ

**สำรองข้อมูล** — ระบบสำรองบนเซิร์ฟเวอร์วันละครั้ง แต่ไฟล์สำรองนี้อยู่ในดิสก์เดียวกับฐานข้อมูล จึงช่วยกรณีข้อมูลเสียหายหรือลบผิด ไม่ช่วยกรณีบริการ/ดิสก์ถูกลบ
ให้ผู้ดูแลเข้าเมนู **ผู้ใช้ → ดาวน์โหลดไฟล์สำรอง (.db)** เก็บไว้ที่อื่นเป็นประจำ (แนะนำสัปดาห์ละครั้ง) ไฟล์นี้มีข้อมูลลูกค้า เก็บให้ปลอดภัย อย่าส่งทางแชท/อีเมลสาธารณะ

**ลืมรหัสผ่านผู้ดูแล** — ใน Render เปิดบริการ → แท็บ **Shell** แล้วพิมพ์
```
python manage.py reset-password admin
```
(ผู้ใช้อื่นลืมรหัส: ผู้ดูแลเปิดเมนู ผู้ใช้ → แก้ไข → ตั้งรหัสผ่านใหม่ให้ได้เลย)

**กู้คืนจากไฟล์สำรองบนเซิร์ฟเวอร์** — ใน Shell:
```
cd /var/data
ls backups
rm -f crm.db-wal crm.db-shm
cp backups/crm-2026-11-10.db crm.db
```
แล้วสั่ง Restart บริการ (เปลี่ยนวันที่ให้ตรงกับไฟล์ที่ต้องการ) · การกู้จากไฟล์ที่ดาวน์โหลดไปเก็บเองยังไม่มีปุ่มในหน้าเว็บ ถ้าจำเป็นให้ขอเพิ่มฟีเจอร์นี้

**อัปเดตโปรแกรม** — แก้/อัปโหลดไฟล์ใหม่ขึ้น GitHub แล้ว Render จะ deploy ให้เอง (ช่วง deploy เว็บจะหยุดสั้น ๆ เพราะใช้ดิสก์ถาวร ควรทำนอกเวลางาน) ข้อมูลไม่หาย

## ความปลอดภัยและข้อมูลส่วนบุคคล (PDPA)

ระบบเก็บชื่อ เบอร์โทร ที่อยู่ของลูกค้า ซึ่งเป็นข้อมูลส่วนบุคคล สิ่งที่ระบบทำให้แล้ว: ใช้ https, รหัสผ่านเก็บแบบแฮช, คุกกี้เซสชันแบบ HttpOnly + SameSite, ล็อกการลองรหัสผิดซ้ำ ๆ (5 ครั้ง/10 นาที), จำกัดสิทธิ์ตามบทบาท (เซลล์ส่งออกข้อมูลทั้งหมดหรือลบข้อมูลไม่ได้), เซสชันหมดอายุใน 12 ชั่วโมง, ปิดบัญชีหรือเปลี่ยนรหัสแล้วเครื่องที่ล็อกอินค้างจะหลุดทันที

สิ่งที่ต้องทำเอง:
- ให้พนักงานแต่ละคนใช้บัญชีของตัวเอง ห้ามแชร์รหัส · ปิดบัญชีทันทีเมื่อมีคนลาออก (เมนู ผู้ใช้ → แก้ไข → ปิดใช้งาน)
- ตั้งรหัสผ่านที่เดายาก ไม่ซ้ำกับที่อื่น ระบบยังไม่มียืนยันตัวตนสองชั้น (2FA)
- แจ้งลูกค้าว่าเก็บข้อมูลอะไร เพื่ออะไร (ประกาศความเป็นส่วนตัว) และเก็บเท่าที่จำเป็น — เอกสารนี้ไม่ใช่คำแนะนำทางกฎหมาย หากต้องการความมั่นใจให้ปรึกษาผู้เชี่ยวชาญ

## ข้อจำกัดที่ควรรู้

- แพ็กเกจนี้ **ทดสอบอัตโนมัติแล้ว** (ชุดทดสอบ backend 26 ข้อ และทดสอบหน้าเว็บกับเซิร์ฟเวอร์จริงแบบสองเครื่องแก้พร้อมกัน) แต่ **ยังไม่ได้ทดลอง deploy บน Render จริง** และไม่ได้เปิดดูหน้าตาใน Chrome/มือถือจริง — ขั้นตอนใน Render อาจต่างเล็กน้อยตามหน้าจอล่าสุด ถ้าติดตรงไหนส่งภาพหน้าจอ/ข้อความ error มาได้
- ข้อมูลจากโปรแกรมเวอร์ชันบนเครื่อง (`pongsakul_crm_local`) ยังไม่ถูกย้ายเข้ามาอัตโนมัติ (ถ้ามีข้อมูลจริงที่ต้องการย้าย บอกได้ว่าจะทำเครื่องมือนำเข้า)
- ระบบเล็กนี้เหมาะกับผู้ใช้หลักหน่วยถึงหลักสิบคน ใช้เซิร์ฟเวอร์เครื่องเดียว หากอนาคตมีผู้ใช้มากหรือต้องการระบบที่ไม่หยุดเลยระหว่างอัปเดต ควรย้ายไปใช้ PostgreSQL
- ลืมรหัสผ่านต้องให้ผู้ดูแลรีเซ็ต (ยังไม่มีอีเมลรีเซ็ตรหัส)
